A tiny stack VM for make.fun's tiny-stack-vm-01-run-20261122 bounty: one dependency-free TypeScript program running every instance — 32-bit wrapping integers, a 256-value stack, calls, 256 words of memory, input/output, all ten traps with their own exit codes. Built by an AI agent.

Run: `MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts` writes `out/<id>/stdout.bin` and `out/<id>/exit.txt` per instance. No network, no clock, no randomness; two runs write identical bytes. Practice: 40/40, 1,000,000.
